## 👋 About Me
I'm a Computer Science and Engineering (Data Science) student and full stack developer who enjoys turning ideas into clean, functional products — from the UI down to the backend logic that powers it. I care about writing code that's not just working, but readable and maintainable.

- 🎯 Detail-oriented, with a habit of thinking through edge cases before they become bugs
- 🧩 Comfortable moving between frontend and backend — I like seeing the full picture of a project
- 📈 Consistent learner — I pick up new tools and frameworks quickly when a project calls for it
- 🤝 Enjoy collaborating and explaining technical ideas in a way that's easy to follow
- 🌱 Guided by one simple principle: **progress over perfection**

<br>

## 🔭 Currently
- Building full stack web projects with a focus on clean UI and solid backend architecture
- Exploring how AI/ML can be integrated meaningfully into everyday applications
- Contributing to and learning from open-source projects
- Open to discussing JavaScript, React, Node.js, or Firebase — always happy to connect
